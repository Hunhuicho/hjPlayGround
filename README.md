# hjPlayGround

방향키로 즐기는 간단한 미니게임 모음입니다. 빌드나 설치 없이 파일을 브라우저에서 열면 바로 실행됩니다.

| 게임 | 파일 |
| --- | --- |
| 🐍 스네이크 | `index.html` |
| 🚜 탱크 | `tank.html` |

두 게임 모두 흑백 LCD 휴대용 게임기 화면을 본떴고, 시작 화면에서 **쉬움 / 보통** 난이도를 고를 수 있습니다.

---

# 🐍 스네이크

## 실행 방법

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 |
| `스페이스바` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

모바일에서는 화면 아래 방향 버튼을 누르거나, 게임판을 스와이프해서 조작할 수 있습니다.

## 난이도

시작 화면에서 고를 수 있습니다. 기본은 **쉬움**입니다.

| | 쉬움 | 보통 |
| --- | --- | --- |
| 벽 | 지나가면 반대편에서 나옴 | 부딪히면 게임 오버 |
| 속도 | 느림 (260ms), 거의 안 빨라짐 | 보통 (140ms), 점점 빨라짐 |
| 먹이 점수 | +5 | +10 |

## 규칙

- 먹이(마름모)를 먹으면 점수가 오르고 몸이 한 칸 길어집니다.
- 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 난이도별로 브라우저에 따로 저장됩니다.

---

# 🚜 탱크

`tank.html` 을 브라우저에서 열면 실행됩니다. 기본은 **운전석 1인칭 시점**입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 — 누른 방향으로 탱크가 돌아갑니다 |
| `스페이스바` 또는 화면의 `FIRE` 버튼 | 대포 발사 |
| `P` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

## 시점

시작 화면과 일시정지 화면에서 바꿀 수 있습니다. 시점을 바꿔도 판은 초기화되지 않습니다.

- **운전석** — 탱크 안에서 내다보는 1인칭. 앞에 내 포신이 보이고, 오른쪽 아래 작은 지도로 위치를 확인합니다. 눈높이가 낮아 담장 너머는 보이지만 막사는 넘겨다볼 수 없습니다.
- **위에서** — 전장을 내려다보는 2D 시점.

## 전장의 물건

| 물건 | 부서짐 | 설명 |
| --- | --- | --- |
| 담장 | 한 방 | 나무 울타리. 낮아서 운전석에서도 너머가 보입니다 |
| 막사 | 두 방 | 2×2 크기 건물. 한 방 맞으면 무너지기 시작합니다 |
| 바위 | 안 부서짐 | 대포가 튕겨 나갑니다. 확실한 엄폐물 |

## 규칙

- 파란 탱크가 내 탱크, 빨간 탱크가 적입니다.
- 적 탱크를 모두 부수면 이깁니다. 한 대당 +100점, 남은 목숨은 한 개당 +200점입니다.
- 피격당하면 목숨이 하나 줄고, 다시 나올 때 잠깐 무적입니다 (운전석 시점에서는 해치 테두리가 붉게 물듭니다).

## 난이도

| | 쉬움 | 보통 |
| --- | --- | --- |
| 목숨 | 5 | 3 |
| 적 탱크 | 8대 (동시 2대) | 12대 (동시 3대) |
| 적 이동 속도 | 58 | 92 |
| 적 발사 간격 | 2.0초 | 1.1초 |
