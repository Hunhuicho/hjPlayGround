# hjPlayGround

키보드로 즐기는 간단한 미니게임 모음입니다. 빌드나 설치 없이 파일을 브라우저에서 열면 바로 실행됩니다.

| 게임 | 파일 |
| --- | --- |
| 🐍 스네이크 | `index.html` |
| 🚜 탱크 | `tank.html` |
| 🔢 숫자 맞히기 | `number.html` |

스네이크는 흑백 LCD 휴대용 게임기 화면을, 탱크는 컬러 만화풍 전장을, 숫자 맞히기는 호박색 표시관이 달린 주머니 계산기를 본떴습니다. 세 게임 모두 시작 화면에서 난이도를 고를 수 있습니다. 스네이크는 쉬움 / 보통, 탱크는 매우 쉬움 / 쉬움 / 보통, 숫자 맞히기는 쉬움 / 보통 / 어려움이고, 기본은 각각 가장 쉬운 쪽입니다. 최고 점수는 게임별 · 난이도별로 브라우저에 따로 저장됩니다.

---

# 🐍 스네이크

## 실행 방법

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 |
| `스페이스바` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

모바일에서는 화면 아래 방향 버튼을 누르거나, 게임판을 스와이프해서 조작할 수 있습니다.

## 난이도

시작 화면에서 고를 수 있습니다. 기본은 **쉬움**입니다.

| | 쉬움 | 보통 |
| --- | --- | --- |
| 벽 | 지나가면 반대편에서 나옴 | 부딪히면 게임 오버 |
| 속도 | 느림 (260ms), 거의 안 빨라짐 | 보통 (140ms), 점점 빨라짐 |
| 먹이 점수 | +5 | +10 |

## 규칙

- 먹이(마름모)를 먹으면 점수가 오르고 몸이 한 칸 길어집니다.
- 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 난이도별로 브라우저에 따로 저장됩니다.

# 🚜 탱크

`tank.html` 을 브라우저에서 열면 실행됩니다. 기본은 **운전석 1인칭 시점**입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 — 누른 방향으로 탱크가 돌아갑니다 |
| `스페이스바` 또는 화면의 `FIRE` 버튼 | 대포 발사 |
| `P` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

## 시점

시작 화면과 일시정지 화면에서 바꿀 수 있습니다. 시점을 바꿔도 판은 초기화되지 않습니다.

- **운전석** — 탱크 안에서 내다보는 1인칭. 앞에 내 포신이 보이고, 오른쪽 아래 작은 지도로 위치를 확인합니다. 눈높이가 낮아 담장 너머는 보이지만 막사는 넘겨다볼 수 없습니다. 바위는 칸마다 다르게 찌그러진 덩어리로, 막사는 박공 지붕을 얹은 건물로 세워집니다.
- **위에서** — 전장을 내려다보는 2D 시점.

## 전장의 물건

전부 부술 수 있고, 단단할수록 여러 방이 필요합니다.

| 물건 | 부서짐 | 설명 |
| --- | --- | --- |
| 담장 | 한 방 | 기둥에 가로대를 걸친 나무 울타리. 낮아서 운전석에서도 너머가 보입니다 |
| 막사 | 두 방 | 경사 지붕을 얹은 2×2 건물. 한 방 맞으면 무너지기 시작합니다 |
| 바위 | 세 방 | 맞을 때마다 금이 가며 조각이 떨어져 작아집니다. 가장 든든한 엄폐물 |

## 규칙

- 파란 탱크가 내 탱크, 빨간 탱크가 적입니다.
- 적 탱크를 모두 부수면 이깁니다. 한 대당 +100점, 남은 목숨은 한 개당 +200점입니다.
- 피격당하면 목숨이 하나 줄고, 다시 나올 때 잠깐 무적입니다 (운전석 시점에서는 해치 테두리가 붉게 물듭니다).

## 난이도

기본은 **매우 쉬움**입니다.

| | 매우 쉬움 | 쉬움 | 보통 |
| --- | --- | --- | --- |
| 목숨 | 9 | 5 | 3 |
| 적 탱크 | 5대 (동시 1대) | 8대 (동시 2대) | 12대 (동시 3대) |
| 적 이동 속도 | 32 | 58 | 92 |
| 적 발사 간격 | 3.2초 | 2.0초 | 1.1초 |
| 적 포탄 속도 | 95 | 155 | 237 |
| 다시 나온 뒤 무적 | 2.6초 | 1.5초 | 1.2초 |

매우 쉬움에서는 적이 한 번에 한 대만 나오고, 아주 느리게 움직이며 좀처럼 쏘지 않습니다. 쏘더라도 포탄이 느려서 피할 수 있습니다.

# 🔢 숫자 맞히기

`number.html` 을 브라우저에서 열면 실행됩니다. 컴퓨터가 숨긴 수를 정해진 기회 안에 맞히는 게임입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `0` – `9` | 숫자 입력 |
| `Enter` | 넣기 (시작 화면에서는 게임 시작) |
| `Backspace` | 한 글자 지우기 |
| `Esc` 또는 `Delete` | 입력한 숫자 전부 지우기 |
| `R` | 다시 시작 |

화면 오른쪽 계산기 자판으로도 똑같이 조작할 수 있어서, 모바일에서도 그대로 즐길 수 있습니다.

## 규칙

- 숫자를 넣으면 숨은 수가 그보다 큰지(`▲`) 작은지(`▼`) 알려줍니다.
- 범위 밖의 수나 이미 넣었던 수는 안내만 하고 기회를 쓰지 않습니다.
- 지난 시도는 화면 아래에 순서대로 남습니다.
- 기회를 모두 쓰면 게임 오버이고, 숨은 수를 알려줍니다.

## 난이도

기본은 **쉬움**입니다.

| | 쉬움 | 보통 | 어려움 |
| --- | --- | --- | --- |
| 범위 | 1 – 50 | 1 – 100 | 1 – 500 |
| 기회 | 10번 | 8번 | 10번 |
| 근접 힌트 | 있음 | 없음 | 없음 |
| 남은 기회당 점수 | 10 | 25 | 40 |

쉬움에서는 위/아래 힌트와 함께 `뜨거워요` `미지근해요` 처럼 얼마나 가까운지도 알려줍니다.

기회는 반씩 좁혀 가면 필요한 횟수(각각 6 / 7 / 9번)보다 넉넉하게 주어집니다.

## 점수

맞혔을 때 `(남은 기회 + 1) × 난이도 점수` 를 받습니다. 적게 넣어 맞힐수록 높고, 마지막 기회에 맞혀도 한 몫은 챙깁니다.
