# hjPlayGround

키보드로 즐기는 간단한 미니게임 모음입니다. 빌드나 설치 없이 파일을 브라우저에서 열면 바로 실행됩니다.

| 게임 | 파일 |
| --- | --- |
| 🐍 스네이크 | `index.html` |
| 🚜 탱크 | `tank.html` |
| 🔢 숫자 길 | `number.html` |

스네이크는 흑백 LCD 휴대용 게임기 화면을, 탱크는 컬러 만화풍 전장을, 숫자 길은 색색의 블록으로 깔린 길을 본떴습니다. 세 게임 모두 시작 화면에서 난이도를 고를 수 있습니다. 스네이크는 쉬움 / 보통, 탱크는 매우 쉬움 / 쉬움 / 보통이고, 숫자 길은 난이도 대신 **배운 데까지**(유치원 / 초등학교 / 중학교 → 학년 → 학기 → 단원)를 고릅니다. 기록은 게임별로, 숫자 길은 단원별로 브라우저에 따로 저장됩니다.

---

# 🐍 스네이크

## 실행 방법

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 |
| `스페이스바` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

모바일에서는 화면 아래 방향 버튼을 누르거나, 게임판을 스와이프해서 조작할 수 있습니다.

## 난이도

시작 화면에서 고를 수 있습니다. 기본은 **쉬움**입니다.

| | 쉬움 | 보통 |
| --- | --- | --- |
| 벽 | 지나가면 반대편에서 나옴 | 부딪히면 게임 오버 |
| 속도 | 느림 (260ms), 거의 안 빨라짐 | 보통 (140ms), 점점 빨라짐 |
| 먹이 점수 | +5 | +10 |

## 규칙

- 먹이(마름모)를 먹으면 점수가 오르고 몸이 한 칸 길어집니다.
- 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 난이도별로 브라우저에 따로 저장됩니다.

# 🚜 탱크

`tank.html` 을 브라우저에서 열면 실행됩니다. 기본은 **운전석 1인칭 시점**입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 — 누른 방향으로 탱크가 돌아갑니다 |
| `스페이스바` 또는 화면의 `FIRE` 버튼 | 대포 발사 |
| `P` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

## 시점

시작 화면과 일시정지 화면에서 바꿀 수 있습니다. 시점을 바꿔도 판은 초기화되지 않습니다.

- **운전석** — 탱크 안에서 내다보는 1인칭. 앞에 내 포신이 보이고, 오른쪽 아래 작은 지도로 위치를 확인합니다. 눈높이가 낮아 담장 너머는 보이지만 막사는 넘겨다볼 수 없습니다. 바위는 칸마다 다르게 찌그러진 덩어리로, 막사는 박공 지붕을 얹은 건물로 세워집니다.
- **위에서** — 전장을 내려다보는 2D 시점.

## 전장의 물건

전부 부술 수 있고, 단단할수록 여러 방이 필요합니다.

| 물건 | 부서짐 | 설명 |
| --- | --- | --- |
| 담장 | 한 방 | 기둥에 가로대를 걸친 나무 울타리. 낮아서 운전석에서도 너머가 보입니다 |
| 막사 | 두 방 | 경사 지붕을 얹은 2×2 건물. 한 방 맞으면 무너지기 시작합니다 |
| 바위 | 세 방 | 맞을 때마다 금이 가며 조각이 떨어져 작아집니다. 가장 든든한 엄폐물 |

## 규칙

- 파란 탱크가 내 탱크, 빨간 탱크가 적입니다.
- 적 탱크를 모두 부수면 이깁니다. 한 대당 +100점, 남은 목숨은 한 개당 +200점입니다.
- 피격당하면 목숨이 하나 줄고, 다시 나올 때 잠깐 무적입니다 (운전석 시점에서는 해치 테두리가 붉게 물듭니다).

## 난이도

기본은 **매우 쉬움**입니다.

| | 매우 쉬움 | 쉬움 | 보통 |
| --- | --- | --- | --- |
| 목숨 | 9 | 5 | 3 |
| 적 탱크 | 5대 (동시 1대) | 8대 (동시 2대) | 12대 (동시 3대) |
| 적 이동 속도 | 32 | 58 | 92 |
| 적 발사 간격 | 3.2초 | 2.0초 | 1.1초 |
| 적 포탄 속도 | 95 | 155 | 237 |
| 다시 나온 뒤 무적 | 2.6초 | 1.5초 | 1.2초 |

매우 쉬움에서는 적이 한 번에 한 대만 나오고, 아주 느리게 움직이며 좀처럼 쏘지 않습니다. 쏘더라도 포탄이 느려서 피할 수 있습니다.

# 🔢 숫자 길

`number.html` 을 브라우저에서 열면 실행됩니다. 색색의 블록으로 깔린 길을 아바타가 걸어가고, 갈림길마다 나오는 문제의 답을 골라 나아가는 게임입니다.

## 배운 데까지 고르기

난이도 대신 **어디까지 배웠는지**를 고릅니다.

- **유치원** — 숫자 / 덧셈 / 뺄셈
- **초등학교** — 1~6학년 → 1·2학기 → 그 학기의 단원 (예: 3학년 1학기 → 3. 나눗셈)
- **중학교** — 1~3학년 → 1·2학기 → 그 학기의 단원 (예: 3학년 1학기 → 3. 이차방정식)

고른 단원의 내용으로 문제가 나옵니다. `원` 단원이면 반지름과 지름, `피타고라스 정리` 단원이면 빗변, `평균과 가능성` 단원이면 평균이 나오는 식입니다. 모두 98개 단원이 들어 있고, 마지막에 고른 단원은 저장되어 다음에 열면 그대로 시작합니다.

> 중학교는 3학년까지라 1~3학년으로 넣었습니다. 4학년이 따로 필요하시면 말씀해 주세요.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` (또는 `A` `D`) | 왼쪽 길 / 오른쪽 길 고르기 |
| `↑` 또는 `스페이스바` | 점프 |
| `P` | 일시정지 / 계속하기 |
| `R` | 지금 스테이지 처음부터 |
| `Esc` | 단원 고르기로 |

화면 아래 `◀` `JUMP` `▶` 단추로도 조작할 수 있습니다. 화면을 직접 눌러도 되는데, 위쪽 절반은 좌우로 길 고르기, 아바타 언저리는 점프입니다.

## 길 위의 것들

| | 설명 |
| --- | --- |
| **갈림길** | 길이 두 갈래로 갈라지고, 그 사이 표지판에 문제가 적혀 있습니다. 각 길 위에 답이 하나씩 놓여 있으니 맞는 쪽으로 들어가면 됩니다 |
| **끊긴 길** | 바닥이 뚫려 있습니다. 앞에 `∧∧` 표시가 새겨져 있고, `↑` 로 뛰어넘습니다 |
| **금 간 타일** | 빛바랜 회색 타일. 밟으면 **3초에 한 칸씩** 차례로 무너져 구멍이 됩니다 |
| **무지개 계단** | 스테이지 끝. 올라가면 다음 스테이지입니다 |

끊긴 곳은 반드시 건널 수 있는 폭입니다. 한 번 뛰면 속도 × 0.75 만큼 나아가는데 구멍은 속도 × 0.26 만 벌어져 있어서, 언제 누르든 **0.46초쯤의 여유** 안이면 건너갑니다.

## 스테이지

한 단원은 **스테이지 5개**, 스테이지 하나는 **문제 4개**입니다.

- 답을 틀리거나 구멍에 빠지면 **그 스테이지를 처음부터** 다시 갑니다. 이미 깬 스테이지는 그대로 남습니다.
- 스테이지를 하나 깰 때마다 걷는 속도가 조금 빨라지고, 끊긴 길과 금 간 타일도 조금 더 자주 나옵니다.
- 걷는 속도는 학교급과 학년에 따라 다릅니다. 유치원이 가장 느리고 중학교 3학년이 가장 빠릅니다.
- 최고 기록은 단원마다 따로 저장됩니다.

## 아바타와 상점

화면 오른쪽 위의 작은 가방 아이콘이 상점입니다. 옷은 9벌 있습니다 — 기본 티셔츠, 빨간 후드티, 노란 우비, 우주복, 기사 갑옷, 마법사 로브, 닌자복, 공주 드레스, 무지개 망토.

- **스테이지 5개를 모두 끝내면 옷을 한 벌 고를 수 있습니다.** 끝내기 전에는 상점에 들어가도 구경만 됩니다.
- 이미 가진 옷은 아무 때나 눌러서 갈아입을 수 있습니다.
- 가진 옷과 입은 옷은 브라우저에 저장됩니다.
