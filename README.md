# hjPlayGround

방향키로 즐기는 간단한 미니게임 모음입니다. 빌드나 설치 없이 파일을 브라우저에서 열면 바로 실행됩니다.

| 게임 | 파일 |
| --- | --- |
| 🐍 스네이크 | `index.html` |
| 🚜 탱크 | `tank.html` |

두 게임 모두 흑백 LCD 휴대용 게임기 화면을 본떴고, 시작 화면에서 **쉬움 / 보통** 난이도를 고를 수 있습니다.

---

# 🐍 스네이크

## 실행 방법

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 |
| `스페이스바` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

모바일에서는 화면 아래 방향 버튼을 누르거나, 게임판을 스와이프해서 조작할 수 있습니다.

## 난이도

시작 화면에서 고를 수 있습니다. 기본은 **쉬움**입니다.

| | 쉬움 | 보통 |
| --- | --- | --- |
| 벽 | 지나가면 반대편에서 나옴 | 부딪히면 게임 오버 |
| 속도 | 느림 (260ms), 거의 안 빨라짐 | 보통 (140ms), 점점 빨라짐 |
| 먹이 점수 | +5 | +10 |

## 규칙

- 먹이(마름모)를 먹으면 점수가 오르고 몸이 한 칸 길어집니다.
- 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 난이도별로 브라우저에 따로 저장됩니다.

---

# 🚜 탱크

`tank.html` 을 브라우저에서 열면 실행됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 — 누른 방향으로 포신이 돌아갑니다 |
| `스페이스바` 또는 화면의 `FIRE` 버튼 | 대포 발사 |
| `P` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

## 규칙

- 속이 밝은 탱크가 내 탱크, 꽉 찬 검은 탱크가 적입니다.
- 적 탱크를 모두 부수면 이깁니다. 한 대당 +100점, 남은 목숨은 한 개당 +200점입니다.
- 대포알은 **벽돌**은 부수지만 **강철벽**(속 빈 네모)은 뚫지 못합니다.
- 피격당하면 목숨이 하나 줄고, 다시 나올 때 잠깐 깜빡이며 무적입니다.

## 난이도

| | 쉬움 | 보통 |
| --- | --- | --- |
| 목숨 | 5 | 3 |
| 적 탱크 | 8대 (동시 2대) | 12대 (동시 3대) |
| 적 이동 속도 | 45 | 72 |
| 적 발사 간격 | 2.0초 | 1.1초 |
