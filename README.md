# hjPlayGround

방향키로 즐기는 간단한 스네이크 미니게임입니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 실행됩니다. 빌드나 설치가 필요 없습니다.

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` (또는 `WASD`) | 이동 |
| `스페이스바` | 일시정지 / 계속하기 |
| `R` | 다시 시작 |

모바일에서는 화면 아래 방향 버튼을 누르거나, 게임판을 스와이프해서 조작할 수 있습니다.

## 규칙

- 빨간 먹이를 먹으면 점수 +10, 몸이 한 칸 길어집니다.
- 먹을수록 속도가 조금씩 빨라집니다.
- 벽이나 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 브라우저에 저장됩니다.
